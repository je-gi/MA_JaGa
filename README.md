# 🌸 Forget me not 
«Forget me not» is a single-player educational escape room designed to introduce players to Unity. Set in a workshop, the player solves four puzzles – each based on a phase of Kolb’s learning cycle – to help a forgetful workshop owner rebuild a robot. With each completed challenge, new robot parts are unlocked. The game combines storytelling, curiosity, and hands-on learning in a compact, engaging format.
